Agent Muzyk · prompt do Flow Music

Pomysł wchodzi. Prompt wychodzi.

Złóż prompt muzyczny w kilka kliknięć albo poproś AI o gotowy tekst i styl. Wynik wklejasz w generator muzyki.

Nastrój (wybierz do 2)
Instrumenty (wybierz do 4)
Wykluczenia

Ten tryb pisze za Ciebie styl i oryginalny tekst. Potrzebny jest własny klucz API z console.anthropic.com. Klucz idzie tylko do Anthropic, nie do tej strony ani na GitHub.

Gotowy prompt wklej w flowmusic.app. Generatory są losowe: zwykle trzeba 2–4 podejść. Zmieniaj jedną rzecz naraz. Kod agenta: github.com/mega916/flow-music-agent
