# Gatunki i tagi — ściąga

Tagi pisz po angielsku. Wybieraj po jednym z każdej grupy, nie wszystko naraz.

## Gatunki i podgatunki

| Kierunek | Przykładowe tagi |
|---|---|
| Pop | synth-pop, dream pop, indie pop, electropop, bedroom pop |
| Rock | alt rock, garage rock, post-punk, shoegaze, soft rock |
| Folk / akustyk | indie folk, singer-songwriter, acoustic ballad, country folk |
| Elektronika | lo-fi house, deep house, synthwave, ambient, downtempo, drum and bass |
| Hip-hop | boom bap, trap, lo-fi hip-hop, melodic rap |
| Jazz / soul | smooth jazz, neo-soul, bossa nova, swing |
| Polskie klimaty | disco polo, biesiadna, szanty, poezja śpiewana |
| Filmowe | cinematic, orchestral, epic trailer, piano score |
| Metal | heavy metal, doom, power metal |

## Tempo (BPM)

| Nastrój | BPM |
|---|---|
| Bardzo wolno, senne | 60–75 |
| Spokojnie, ballada | 75–95 |
| Średnio, marsz, pop | 95–120 |
| Taneczne | 120–135 |
| Energiczne | 135–170 |

## Nastrój

nostalgic, hopeful, melancholic, euphoric, dark, dreamy, tense, playful, romantic, defiant, peaceful, triumphant

## Wokal

- Płeć i barwa: `male baritone`, `female alto`, `airy female`, `raspy male`, `warm duet`
- Sposób: `breathy`, `belted chorus`, `whispered verses`, `soulful`, `deadpan`, `falsetto accents`
- Chór: `stacked harmonies`, `gang vocals`, `choir pads`
- Bez wokalu: `instrumental`

## Instrumenty

guitar (`fingerpicked`, `clean electric`, `distorted`), piano (`felt piano`, `upright`), synth (`warm pad`, `arpeggiated`, `analog bass`), drums (`brushed`, `punchy`, `808`, `drum machine`), strings (`cello`, `violin section`), `accordion`, `harmonica`, `saxophone`, `trumpet`

## Produkcja

`lo-fi tape warmth`, `crisp modern`, `wide stereo`, `dry and intimate`, `heavy reverb`, `analog warmth`, `vinyl crackle`, `live-in-room feel`

## Struktury

- **Pop klasyczny:** Intro, Verse 1, Pre-Chorus, Chorus, Verse 2, Pre-Chorus, Chorus, Bridge, Chorus, Outro
- **Krótki (reels/TikTok, ok. 30–60 s):** Intro, Verse, Chorus, Outro
- **Instrumental:** Intro, Theme A, Theme B, Build, Theme A, Outro
- **Ballada:** Verse 1, Verse 2, Chorus, Verse 3, Bridge, Chorus

## Wykluczenia (przykłady)

`no autotune`, `no rap`, `no choir`, `no heavy distortion`, `no spoken intro`, `no drums`, `no electronic elements`

## Nazwy artystów

Nie używaj nazw żyjących artystów. Opisz brzmienie:

| Zamiast nazwiska | Napisz |
|---|---|
| "jak ta gwiazda lat 80." | `80s synth-pop, gated reverb drums, glossy synth pads` |
| "jak ten raper" | `laid-back boom bap, dusty samples, relaxed flow` |
| "jak ta folkowa wokalistka" | `intimate female folk vocal, fingerpicked guitar, sparse arrangement` |
