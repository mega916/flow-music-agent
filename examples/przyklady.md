# Przykłady

Trzy gotowe utwory pokazujące, jak działa agent. Teksty są oryginalne.

---

## 1. Jingle dla firmy spawalniczej (instrumental, krótki)

**Pomysł:** 30-sekundowy dżingiel do rolek, pewny siebie, "stal i precyzja".

**STYL:**
```
corporate electronic, confident, 108 BPM,
punchy synth bass, crisp claps, short metallic percussion hits,
instrumental, modern crisp production,
quick build then strong final hit, clean ending
```

**TEKST:**
```
[Instrumental]
```

**WYKLUCZENIA:**
```
no vocals, no long intro, no fade-out
```

**Następny krok:** jeśli brzmi zbyt "korporacyjnie", zamień `corporate electronic` na `industrial electronic`.

---

## 2. Piosenka o poranku po nocnej zmianie (indie folk)

**STYL:**
```
indie folk, warm acoustic, 88 BPM, A minor,
tired but hopeful, nostalgic,
fingerpicked acoustic guitar, soft upright bass, brushed drums,
breathy male vocal, intimate close-mic,
organic analog production,
quiet verses, singalong chorus
```

**TEKST:**
```
[Verse 1]
Szary świt na przystanku
Kawa stygnie w dłoni
Cały dzień za mną w plecach
Jeszcze noc mnie goni

[Pre-Chorus]
Jeszcze krok i jeszcze jeden
Dom jest tuż za rogiem

[Chorus]
Wracam do domu, światło już wstaje
Wracam do domu, wszystko jest w miarę
Wracam do domu, i to mi wystarcza
Wracam do domu, jutro też warto

[Verse 2]
Pachnie chleb z piekarni
Ktoś otwiera okna
Zmęczenie jest uczciwe
Kiedy praca skończona

[Chorus]

[Outro]
(gitara solo, wolno wygasa)
```

**WYKLUCZENIA:**
```
no autotune, no rap, no heavy drums, no choir
```

**Następny krok:** jeśli refren jest za cichy, dodaj `bigger chorus, doubled vocals`.

---

## 3. Energetyczny singiel pod trening (dance-pop)

**STYL:**
```
dance-pop, driving, 126 BPM, F minor,
euphoric, determined,
four-on-the-floor kick, pulsing synth bass, bright plucks,
powerful female vocal with belted chorus,
glossy wide production,
big drop-style chorus
```

**TEKST:**
```
[Verse 1]
Budzik dzwoni, wstaję
Jeszcze ciemno w oknach
Dziś nie pytam siebie
Czy mi się opłaca

[Chorus]
Jeszcze raz, jeszcze raz
Moje serce bije w takt
Jeszcze raz, jeszcze raz
Nie zatrzyma mnie dziś nikt

[Verse 2]
Pot na czole mówi
Że to ma sens
Każdy mały krok
Buduje mój dzień

[Bridge]
(cisza, tylko bas i oddech)

[Chorus]
```

**WYKLUCZENIA:**
```
no rap, no slow intro, no acoustic guitar
```

**Następny krok:** jeśli wokal brzmi zbyt ostro, zamień `powerful` na `warm`.
